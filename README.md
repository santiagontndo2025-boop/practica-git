# Práctica Git: archivos de texto

Repositorio creado para practicar los comandos básicos de Git y la redacción de mensajes de commit claros y descriptivos.

## Archivos

- `documento1.txt`: datos sobre Nintendo (origen, cartas hanafuda y Mario).
- `documento2.txt`: datos sobre fisicoculturismo (Mr. Olympia y campeones).
- `arte.txt`: datos sobre arte (Mona Lisa y Fernando Botero). Antes se llamaba `documento3.txt`.

## Comandos utilizados

- `git clone`: descargar el repositorio.
- `git status` y `git diff`: revisar cambios.
- `git add` y `git commit -m`: registrar cambios.
- `git mv` y `git rm`: renombrar y eliminar archivos.
- `git log --oneline`: ver el historial.
- `git push origin main`: subir los cambios a GitHub.
